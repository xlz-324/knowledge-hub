# 架构决策记录（ADR）

记录影响业务边界、数据、安全、部署或长期维护的关键决策。

| 编号                                                   | 决策                                    | 状态     |
| ------------------------------------------------------ | --------------------------------------- | -------- |
| [0001](./0001-modular-monolith-and-pnpm-workspaces.md) | 模块化单体、前后端分离与 pnpm workspace | Accepted |

## 新记录模板

```markdown
# ADR-xxxx：标题

- 日期：
- 状态：Proposed

## 背景

真实问题、约束与目标。

## 决策

选择的方案和边界。

## 备选方案

真正考虑过的 1～3 个方案。

## 取舍

收益、代价和为什么不选其他方案。

## 影响

开发、测试、安全、部署、运维的影响。

## 验证与重审条件

如何证明有效；什么情况下重新评估。
```
